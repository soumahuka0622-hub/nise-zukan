# nise-zukan
ネット上に存在する「偽りのアカウント」「仮面の人格」を分類・記録する観察図鑑。 言語特徴・行動パターン・心理的背景を冷静に分析する。

## note「三豚界隈」

「三豚界隈」タブでは、noteの公開ハッシュタグ記事をランダム順で表示します。Vercelの [`api/note-tag.js`](./api/note-tag.js) がnoteの公開APIから全ページを取得するため、タグ記事の追加後、ページの再読み込みまたは「記事を更新」から反映できます。APIの応答は最大1分キャッシュされます。取得に失敗した場合は [`note-tag-data.js`](./note-tag-data.js) の保存済み記事を表示します。
